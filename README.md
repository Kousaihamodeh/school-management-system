# School Management System

A backend school management system built with Laravel and PHP, following a clean architecture approach with Services, Repositories, Policies, Form Requests, and Eloquent ORM.

## Features

- Student management
- Teacher management
- Parent management
- Class and section management
- Attendance tracking
- Examination and grading management
- Fee and invoice management
- Role-based authorization

## Architecture

- Controllers
- Services
- Repositories
- Form Requests
- Policies
- Eloquent Models
- PHP Enums
- Database Seeders

## Technologies

- PHP 8.2+
- Laravel 11
- MySQL
- Eloquent ORM
- Spatie Laravel Permission
